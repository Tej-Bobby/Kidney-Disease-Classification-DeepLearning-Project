# Kidney Disease Classification Deep Learning Project

## How to Run the Project

### STEP 01 - Clone the Repository

```bash
git clone <your-github-repository-link>
```

### STEP 02 - Move into the Project Directory

```bash
cd Kidney-Disease-Classification-DeepLearning-Project
```

### STEP 03 - Create a Conda Environment

```bash
conda create -n kidney python=3.10 -y
```

### STEP 04 - Activate the Environment

```bash
conda activate kidney
```

### STEP 05 - Install the Requirements

```bash
pip install -r requirements.txt
```
